# VPN 与代理协议：从客户端、订阅到网络连接

VPN、代理客户端、订阅和传输协议是不同层面的概念。客户端负责读取配置并建立连接，订阅通常用于分发节点或配置，协议则决定具体的通信方式。

## 常见协议与技术

### WireGuard

WireGuard 是现代 VPN 协议，配置结构相对简洁，适合需要较低开销和较好性能的 VPN 场景。

### Shadowsocks

Shadowsocks 是常见的代理协议生态之一，通常通过客户端配置服务器、端口、加密方式等参数建立连接。

### VLESS

VLESS 常见于基于 Xray 等内核的代理配置。实际使用时还会涉及传输层、TLS、Reality 等其他配置项，因此不能只看协议名称判断最终连接方式。

### VMess

VMess 是较早出现于 V2Ray 生态中的协议。使用时需要客户端和服务端的配置参数保持匹配。

### Trojan

Trojan 常与 TLS 等技术组合使用。实际连接结果除了协议本身，还取决于域名、证书、传输方式和网络环境。

### Hysteria 2

Hysteria 2 面向高延迟或丢包网络环境提供不同于传统 TCP 代理的传输方案。是否适合某个网络，需要结合实际链路测试。

## 订阅是什么

订阅通常是一个用于获取配置或节点信息的地址。不同客户端支持的订阅格式可能不同，因此“有订阅”不等于“所有客户端都能直接导入”。

如果导入失败，优先检查：

- 订阅地址是否有效
- 返回内容是否为客户端支持的格式
- 客户端是否需要转换
- HTTPS/DNS 是否正常
- 订阅是否过期或被服务端限制

## 协议怎么选

不要只根据协议名称判断速度或稳定性。实际体验受到线路、出口、服务器负载、运营商、MTU、DNS、客户端实现以及目标服务等多种因素影响。

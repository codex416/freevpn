# VPN 客户端与平台指南

交个朋友 VPN 可根据设备选择不同客户端。客户端功能、配置格式和版本会变化，使用前应查看对应项目的最新说明。

## Windows

- Clash Verge Rev
- v2rayN
- sing-box

## macOS

- Clash Verge Rev
- V2rayU
- sing-box
- Surge

## Linux

- sing-box
- Clash 系客户端

## iPhone / iPad

- Shadowrocket
- Quantumult X
- Surge
- sing-box

## Android

- Clash Meta
- NekoBox
- V2rayNG
- sing-box

## 客户端选择

Windows 用户可以从 Clash Verge Rev、v2rayN 或 sing-box 开始；macOS 用户可以根据习惯选择 Clash Verge Rev、V2rayU、sing-box 或 Surge；iPhone / iPad 常见选择包括 Shadowrocket、Quantumult X、Surge 和 sing-box；Android 常见选择包括 Clash Meta、NekoBox、V2rayNG 和 sing-box。

具体配置方式应以客户端当前版本支持的格式和官方文档为准。

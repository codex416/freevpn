# 平台与客户端

交个朋友 VPN 面向常见桌面和移动设备提供客户端选择参考。不同客户端的协议支持、配置格式和功能会随版本变化，使用时应以客户端官方文档为准。

## Windows

常见选择：Clash Verge Rev、v2rayN、sing-box。

- Clash Verge Rev：适合习惯 Clash 配置和规则管理的用户。
- v2rayN：Windows 平台常见的图形化客户端。
- sing-box：适合需要跨平台配置和更灵活网络功能的用户。

## macOS

常见选择：Clash Verge Rev、V2rayU、sing-box、Surge。

## Linux

常见选择：sing-box 以及支持相应配置格式的 Clash 系客户端。Linux 环境下通常需要结合发行版、桌面环境和网络管理方式进行配置。

## iPhone / iPad

常见选择：Shadowrocket、Quantumult X、Surge、sing-box。

iOS 客户端对配置格式、系统权限和后台运行机制的支持存在差异，具体以当前版本为准。

## Android

常见选择：Clash Meta、NekoBox、V2rayNG、sing-box。

Android 不同系统版本和厂商对 VPN、后台运行和电池优化的处理可能不同。

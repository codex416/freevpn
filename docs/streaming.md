# 海外流媒体与网络体验：YouTube、Netflix、Disney+

流媒体服务对带宽、延迟、丢包、出口 IP 和地区策略都比较敏感。节点能够连接，并不意味着所有地区内容都可以播放。

## YouTube

YouTube 对网络质量和持续带宽较敏感。播放卡顿时，可以依次检查节点延迟、丢包、出口线路、DNS、客户端代理模式和本地网络质量。

## Netflix

Netflix 的内容库与地区有关。某个节点能够访问 Netflix，并不意味着所有地区内容或所有视频都能够播放。实际结果取决于出口 IP、Netflix 的识别策略和当前服务状态。

## Disney+

Disney+ 同样存在地区内容差异。访问和播放结果可能受到出口地区、IP 类型、网络质量和平台策略影响。

## 流媒体排查

1. 确认客户端已经正确连接节点。
2. 检查当前出口地区是否符合目标服务需求。
3. 更换同地区的其他节点进行对比。
4. 检查 DNS 和 HTTPS 连接是否正常。
5. 如果只有某个平台异常，查看该平台自身的服务状态和地区政策。
6. 如果多个平台同时异常，再检查本地网络、IPv4 / IPv6 和客户端配置。

## 关于地区内容与“解锁”

流媒体平台会持续调整地区识别、IP 策略和内容授权，因此一次测试结果不能代表长期可用性。本项目只提供网络和客户端层面的使用参考。

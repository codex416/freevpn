# VPN 与代理常见问题

## 支持哪些平台？

支持 Windows、macOS、Linux、iPhone、iPad 和 Android 等常见平台。

## Windows 使用什么客户端？

常见选择包括 Clash Verge Rev、v2rayN 和 sing-box。具体选择取决于配置格式、规则需求和使用习惯。

## iPhone / iPad 使用什么客户端？

常见选择包括 Shadowrocket、Quantumult X、Surge 和 sing-box。不同客户端对协议、订阅和规则的支持不同。

## Android 使用什么客户端？

常见选择包括 Clash Meta、NekoBox、V2rayNG 和 sing-box。遇到后台断连时，应检查电池优化和后台运行权限。

## Clash、Shadowrocket、sing-box 和 v2rayN 有什么区别？

它们属于不同客户端或客户端生态，平台支持、配置格式、规则能力和操作方式并不完全相同。可以先根据设备选择，再根据订阅格式和功能需求判断。

## 为什么同一个节点在不同地区体验不同？

跨境网络体验会受到所在地、运营商、出口地区、线路质量、网络拥塞和目标平台策略等因素影响，因此单次测速或一次访问结果不能代表长期体验。

## 为什么网站能打开，但 API 或登录失败？

网页、登录接口和 API 可能使用不同域名或网络链路。建议检查 API 域名解析、代理范围、DNS、TLS 和出口地区，并确认目标服务本身没有故障。

## 为什么 VPN 连上了却打不开网站？

优先检查 DNS、IPv4 / IPv6、代理模式、规则分流和目标域名是否被正确代理。也可以更换同地区的其他节点进行对比。

## 为什么速度慢？

速度受到本地网络、跨境线路、节点负载、出口地区、丢包和目标服务等因素影响。不要只看延迟，建议同时观察带宽和丢包。

## 为什么订阅无法导入？

确认订阅地址有效，并确认返回的配置格式被当前客户端支持。不同客户端并不一定能直接导入同一种订阅格式。

## 如何获取订阅？

进入官方网站注册并登录后，根据页面提示获取订阅信息，再按照[客户端指南](./clients.md)选择适合设备的客户端并导入配置。

## 信息多久更新一次？

官方入口和客户端信息会根据实际变化进行维护。涉及第三方软件、AI 服务和流媒体平台时，应以其官方项目、服务状态和最新政策为准。

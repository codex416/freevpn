# 常见问题

## 支持哪些平台？

交个朋友 VPN 支持 Windows、macOS、Linux、iPhone、iPad 和 Android 等常见平台。

## Windows 使用什么客户端？

常见选择包括 Clash Verge Rev、v2rayN 和 sing-box。具体功能和配置方式以客户端项目的最新版本为准。

## iPhone / iPad 使用什么客户端？

常见选择包括 Shadowrocket、Quantumult X、Surge 和 sing-box。不同客户端的配置格式和功能有所不同。

## Android 使用什么客户端？

常见选择包括 Clash Meta、NekoBox、V2rayNG 和 sing-box。

## 为什么不同地区的网络体验不同？

跨境网络体验会受到用户所在地、运营商、出口地区、线路质量、网络拥塞以及目标平台策略等因素影响。

## 为什么某个海外服务突然无法访问？

第三方服务的地区政策、账号政策、网络策略和服务状态可能发生变化。建议先确认本地网络、节点状态和客户端配置，再查看对应平台的官方状态或公告。

## 如何获取订阅？

进入官方网站注册并登录后，根据页面提示获取订阅信息，再将配置导入对应客户端。

## 信息多久更新一次？

官方入口和客户端信息会根据实际变化进行维护。涉及第三方软件时，应以其官方项目和最新版本为准。

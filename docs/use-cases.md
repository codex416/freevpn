# VPN 与代理的常见使用场景

网络工具的实际用途并不只有访问网页。不同场景对延迟、带宽、出口地区、DNS 和客户端代理范围的要求不同。

## AI 工具

ChatGPT、Claude、Gemini、Midjourney 等服务可能受到地区、账号、出口网络和服务状态影响。网页访问正常并不代表 API 或全部功能正常。

参考：[AI 服务与网络连接](./ai-services.md)

## GitHub 与开发工作

GitHub、软件包仓库、文档站和开发 API 对 DNS、HTTPS、代理稳定性比较敏感。开发环境中建议确认终端、Git、包管理器和浏览器是否使用了相同的网络路径。

## 海外流媒体

YouTube、Netflix、Disney+ 等平台的内容和可用性与地区、出口 IP 和平台策略有关。具体结果需要以当前节点和平台状态为准。

参考：[海外流媒体与网络体验](./streaming.md)

## 跨境电商与远程工作

跨境电商、海外网站访问和远程协作通常更关注连接稳定性、出口地区和长连接表现。使用前应确认目标平台允许的网络和账号行为，并遵守其服务条款。

## 日常网络访问

普通网页访问更适合从 DNS、延迟、稳定性和客户端兼容性出发选择网络配置，而不是只比较某个节点的瞬时测速结果。

## 如何根据场景选择

| 场景 | 优先关注 |
| --- | --- |
| AI / API | 稳定性、DNS、出口地区、HTTPS |
| GitHub / 开发 | DNS、HTTPS、终端代理、长连接 |
| 视频流媒体 | 带宽、丢包、出口地区 |
| 跨境工作 | 稳定性、延迟、出口地区 |
| 日常网页 | DNS、延迟、连接稳定性 |

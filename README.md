## 常见使用场景

### AI 工具

适用于 ChatGPT、Claude、Gemini、Midjourney 等 AI 服务，也适合 AI 开发、API 调试以及日常资料检索等跨境网络场景。具体可用性取决于节点地区、服务商策略和当地网络环境。

详细说明：[`docs/ai-services.md`](./docs/ai-services.md)

### 海外流媒体

可用于 YouTube、Netflix、Disney+ 等海外流媒体服务。实际可访问的地区、内容和视频质量取决于具体节点、出口地区、平台政策以及当地网络环境。

详细说明：[`docs/streaming.md`](./docs/streaming.md)

### 跨境工作与电商

适用于跨境电商、海外网站访问、资料查询以及 Amazon、Shopee、Mercari、TikTok 等平台相关工作场景。具体平台的地区限制、账号政策和服务条款请以对应平台规则为准。

## 线路与网络体验

服务包含不同类型的跨境网络线路，部分节点采用 IEPL / IPLC 等专线方案。不同节点的延迟、带宽、出口地区和实际体验可能存在差异，建议结合所在地和具体用途选择节点。

## 如何开始使用

1. 打开官方网站并注册账号。
2. 登录后按照页面提示选择服务方案。
3. 获取订阅信息或配置内容。
4. 在对应客户端中导入订阅并连接节点。

客户端的具体导入方式取决于客户端类型。详细教程可查看本仓库 `docs/` 目录和官方教程站。

## 常见问题

### 交个朋友 VPN 支持哪些设备？

支持 Windows、macOS、Linux、iPhone、iPad 和 Android 等常见平台。

### 交个朋友 VPN 支持 Clash 吗？

支持。Windows 和 macOS 可以根据客户端情况使用 Clash Verge Rev，Android 可以使用 Clash Meta 等 Clash 系客户端。

### iPhone 用什么客户端？

iPhone 和 iPad 常见选择包括 Shadowrocket、Quantumult X、Surge 和 sing-box。不同客户端的配置格式和功能有所不同。

### Android 用什么客户端？

Android 常见选择包括 Clash Meta、NekoBox、V2rayNG 和 sing-box。

### Windows 用什么客户端？

Windows 常见选择包括 Clash Verge Rev、v2rayN 和 sing-box。

### macOS 用什么客户端？

macOS 常见选择包括 Clash Verge Rev、V2rayU、sing-box 和 Surge。

### 为什么同一个节点在不同地区体验不同？

跨境网络体验会受到用户所在地、运营商、出口地区、线路质量、网络拥塞和目标平台策略等因素影响，因此不能仅根据单次测试结果判断长期体验。

### 如何获取订阅？

进入官方网站注册并登录后，根据页面提示获取订阅信息，再将配置导入对应客户端。
